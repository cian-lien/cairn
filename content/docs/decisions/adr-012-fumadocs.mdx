**状态**：已采纳
**参与**：[成员]

## 背景

团队经验散落在聊天记录、云文档和个人脑子里，新人上手和排障时找不到资料。需要一个能搜、版本可追溯、维护成本低的知识库。

## 候选方案

| 方案                        | 优点                                       | 缺点                                   |
| --------------------------- | ------------------------------------------ | -------------------------------------- |
| Outline（自托管）           | 网页编辑体验好，实时协作                   | 需要服务器、Postgres、Redis，运维成本高 |
| VitePress                   | 轻量、构建快                               | 需要多工作区、自定义首页时扩展性一般   |
| **Fumadocs + Next.js**      | React 生态、组件丰富、内置搜索和多工作区   | 只能在本地写 Markdown，没有网页编辑器 |

## 决定

选用 Fumadocs。团队以前端为主，React 技术栈零学习成本；内容放在 Git 里，和代码走同一套 PR 流程；部署在 Vercel，不用维护服务器。

## 后果

- 写文档需要会用 Git，非技术成员门槛稍高，可以通过「在 GitHub 上编辑」降低门槛
- 以后如果需要网页编辑和实时协作，再评估 Outline 等方案
