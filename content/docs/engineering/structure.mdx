## 工作区

`content/docs` 下的每个一级文件夹都是一个**工作区**，在侧边栏顶部切换。工作区由文件夹里的 `meta.json` 声明：

```json title="content/docs/engineering/meta.json"
{
  "title": "工程手册",
  "description": "代码、部署与排障",
  "icon": "Code",
  "root": true
}
```

想新增一个工作区：建文件夹、写 `meta.json`（`root: true`），再把文件夹名加到 `content/docs/meta.json` 的 `pages` 里。图标颜色在 `lib/shared.ts` 的 `workspaces` 里配置。

## 侧边栏顺序

文件夹里 `meta.json` 的 `pages` 决定顺序，`---标题---` 是分组标题，`...` 表示其余页面按字母排序。
